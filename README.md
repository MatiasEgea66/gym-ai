# Gym AI

App web mobile-first (PWA) con tu plan de entrenamiento semanal: Lunes / Miércoles / Viernes.

- **Inicio**: entrenamiento del día según la fecha, racha semanal y accesos rápidos.
- **Rutina**: los 3 días completos con todos los bloques, ejercicios, series/reps y técnica.
- **Historial**: sesiones completadas, series realizadas y pesos usados.

Cada sesión guiada permite marcar series completadas, registrar el peso usado (se recuerda el último peso por ejercicio) y un timer de descanso entre series. Todo se guarda localmente en el dispositivo.

## Uso

```bash
npm install
npm run dev
```

Es una PWA instalable: abrí la app en el navegador del celular y usá "Agregar a pantalla de inicio" para que funcione como una app nativa (con ícono propio y offline).

## Build

```bash
npm run build
npm run preview
```
